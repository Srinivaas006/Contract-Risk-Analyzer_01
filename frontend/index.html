    About This Project

    This is an NLP-based contract intelligence system built as part of a Data Science & Machine Learning course project.

    🎯 Project Goal

    To build an automated system that helps non-lawyers understand legal contracts by detecting risky clauses and providing plain-language explanations.

    📚 Dataset

    Trained using the CUAD Dataset (Contract Understanding Atticus Dataset) — 510+ commercial contracts with 41 expertly annotated clause categories.

    🛠️ Tech Stack

    • Python + FastAPI
    • HuggingFace Transformers (RoBERTa)
    • spaCy (Named Entity Recognition)
    • sentence-transformers (Embeddings)
    • Tesseract OCR + pdf2image
    • PyTorch

    🔗 API Reference

    • POST /analyze-text/ — Analyze text
    • POST /upload-contract/ — Upload PDF
    • GET /contracts — List analyzed contracts
    • POST /search/ — Semantic search
